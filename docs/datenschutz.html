Das Programm selbst

Der Bilderkatalog liest deine Fotos und deren Angaben (Aufnahmedatum, Kamera, GPS-Position) ausschließlich auf deinem Rechner und speichert den Katalog, die Alben und Vorschaubilder nur dort (im Ordner %LOCALAPPDATA%\bilderkatalog). Orte werden aus einem mitgelieferten Ortsverzeichnis bestimmt, ohne dass Koordinaten übertragen werden. Das Programm schickt keine Bilder, Ortsdaten oder Dateinamen an den Entwickler oder an Dritte.

  • Nach Updates suchen: Nur auf deinen Klick hin fragt das Programm bei GitHub (siehe oben) nach der neuesten Versionsnummer. Dabei werden technisch bedingt deine IP-Adresse und die Programmanfrage an GitHub übertragen, aber keine Inhalte aus deinem Katalog.
  • Optionaler Online-Zugang: Richtest du selbst den Zugang über Microsoft Graph ein, liest das Programm Angaben und Vorschaubilder deiner Fotos direkt bei Microsoft (nur mit Leserechten). Dafür gelten die Datenschutzbestimmungen von Microsoft. Ohne diese Einrichtung findet keine Verbindung zu Microsoft statt.
  • OneDrive-Synchronisierung: Vorschaubilder von Nur-online-Dateien fordert das Programm über Windows an; der auf deinem Rechner installierte OneDrive-Client holt sie wie im Explorer aus deinem eigenen OneDrive. Lädst du Details nach („Details nachladen“, ZIP-Export von Nur-online-Bildern), holt er auf dieselbe Weise die Dateien selbst.
